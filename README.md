1. Luồng kiến trúc DIKW
Data (Dữ liệu): Giá trị thô từ cảm biến (ví dụ: Độ ẩm = 65%, Nhiệt độ = 36°C).
Information (Thông tin): Dữ liệu được gán ngữ cảnh để hiển thị báo cáo/dashboard (ví dụ: "14:00 tại Khu A, Nhiệt độ 36°C").
Knowledge (Tri thức): Thực thi quy tắc cố định  Tự động bật máy bơm khi Nhiệt độ > 35°C.
Wisdom (Trí tuệ): Kết hợp dự báo thời tiết dài hạn  Tự động hoãn/điều chỉnh lượng nước tưới để tránh ngập úng và tiết kiệm tài nguyên.
2. Tính toán dung lượng ổ cứng
Dữ liệu 1 năm: 50MB/ngày 365ngày=18250MB = 17.82GB.
Dung lượng tối thiểu (với giới hạn 70% đĩa):
17.82GB/0.7=25.46GB
Kết luận: Cần chọn ổ cứng/thẻ nhớ dung lượng chuẩn tối thiểu 32GB (khuyên dùng 64GB).
3. Xử lý file cấu hình .env
Hiển thị file ẩn: Bật Hidden Items trong File Explorer (Windows) hoặc dùng lệnh ls -a trong Terminal.
Bảo mật: Thêm .env vào .gitignore để tránh lộ mật khẩu.
